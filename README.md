# Descritivo de instalação e uso da aplicação
<ul>
  <li>1º Criar uma pasta no seu diretorio</li>
  <li>2º Abrir o git bash na pasta</li>
  <li>3º Trocar a branch de master para main, com o comando : git branch -m main</li>
  <li>4º git clone https://github.com/KhianGabriel/NutryDegustFront.git</li>
  <li>5º Abrir o projeto na sua IDE (opcional) VSCode</li>
  <li>6º Baixar o npm, abrindo o terminal no VSCode e colocando o comando: npm install
  <li>6.1 Caso de erro de ativação de scripts, usar esse comando: Set-ExecutionPolicy Unrestricted . Depois executar novamente o comando anterior</li>
  </li>
  <li>7º Instalar o Angular, com o comando: npm install -g @angular/cli</li>
  <li>8º Agora é só rodar o projeto, comando: ng serve ou npm start</li>
  <li>9º Abrir o projeto no navegador: http://localhost:4200/index</li>
</ul>
